# Camada: Util
Ferramentas de apoio que podem ser usadas por qualquer outra camada.

### Componentes:
- **Constantes**: Armazena a String `NAO_INFORMADO`.
- **FormatadorData**: Lógica para gerar o prefixo `20231101T1234`.
- **Normalizador**: Função para remover acentos e facilitar a busca case-insensitive.
- **ParseEndereco**: Os dados estavam vindo nulos porque eu só estava lendo uma String e não convertendo para o objeto.
  Então criei um utilitário responsável por transformar o texto em um Endereco válido, separando os campos e preenchendo corretamente.”
