# 🐾 Sistema de Adoção de Pets
Desafio [ do Dev Karilho | Magro ](https://github.com/karilho/desafioCadastro)
## 📌 Descrição do Projeto

Este projeto é um **Sistema de Adoção de Pets** desenvolvido em **Java**, com o objetivo de gerenciar o cadastro de animais, endereços e processos relacionados à adoção. O sistema foi criado com foco em **prática de lógica de programação, orientação a objetos, manipulação de arquivos e serialização**.

Ele simula o funcionamento básico de uma ONG ou abrigo de animais, permitindo organizar informações de forma estruturada e persistente.

---

## 🎯 Objetivos do Sistema

* Cadastrar pets disponíveis para adoção
* Armazenar e recuperar dados utilizando **arquivos**
* Aplicar conceitos de **Programação Orientada a Objetos (POO)**
* Utilizar **menu interativo**
* Praticar **leitura e escrita de dados**
* Trabalhar com **serialização e desserialização** de objetos

---

## 🛠️ Tecnologias Utilizadas

* **Java** (JDK 17)
* **Paradigma Orientado a Objetos**
* **Manipulação de arquivos** (`BufferedReader`, `Files`, `Path`)
* **Serialização** (`ObjectOutputStream`, `ObjectInputStream`)

## ▶️ Como Executar o Projeto

1. Clone o repositório:

```bash

```

2. Abra o projeto em uma IDE Java (IntelliJ, Eclipse ou VS Code)

3. Compile e execute a classe principal (`Main.java`) dentro de (`view`)

4. Utilize o menu exibido no terminal para interagir com o sistema
